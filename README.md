# sg6-multiactivity

# Project 1: Odd or Even
A program that detects if the number that the user inputs is odd or even. It utilizes the modulo operator.

----------------------
Input Needed:

-Any integer you prefer

----------------------
**Sample Output:**
```text
Enter a number: 17

Odd
```

# Project 2: Grade Evaluation
A program that asks the user for their score, then uses it to determine what their grade category is. 90 and above for A, 80-89 for B, 70-79 for C, and below 70 for D.

---------------------
Input Needed:

-Any grade or score from 0 to 100

---------------------
**Sample Output:**
```text
Enter your score: 83

Grade: B
```

# Project 3: Discount Eligibility Checker
A program that tells you if you are eligible for a discount by asking your age, if you are a senior or a student, and if you have a membership card.

---------------------
Input Needed:
-Y or N when the program asks you if you are a student or not

-Your age

-Y or N when the program asks you if you have a membership card

--------------------
Sample Outputs:

**Sample Output 1:**
```text
Are you a student? Type Y or N: Y
Enter your age: 30
Do you have a membership card? Y
You are eligible for a discount.
```

**Sample Output 2:**
```text
Are you a student? Type Y or N: N
Enter your age: 66
Do you have a membership card? N
You are not eligible for a discount.
```

# HOW TO OPEN AND RUN THE PROGRAMS
Follow these instructions to clone, configure, and execute the project.

### 1. Clone the Repository
Open your terminal and run the following command to download the code from GitHub:
```bash
git clone https://github.com
cd your-repo-name
```

### 2. Open in Visual Studio Code
You can launch the project instantly in VS Code by running:
```bash
code .
```

### 3. Install Dependencies
Install the required packages before running the code:
```bash
# Example for Python:
pip install -r requirements.txt

# Example for Node.js:
npm install
```
